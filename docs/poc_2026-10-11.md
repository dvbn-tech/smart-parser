# Проба Instagram без логина — 11.10.2026

Машина разработчика, IP 176.212.38.65, без прокси, заголовки веб-клиента из конфига.

| Запрос | Результат |
|---|---|
| `GET /api/v1/users/web_profile_info/?username=munique.base_` (первый запрос) | **429**, пустое тело, 0,4 с |
| `GET https://www.instagram.com/` | 200, выданы cookie `csrftoken`, `mid` |
| тот же профиль через 25 с, с cookie и `X-CSRFToken` | **429**, пустое тело |

Вывод: с этого IP веб-эндпоинты Instagram без логина закрыты сразу, без
нагрузки с нашей стороны. Это не ошибка парсера: он корректно классифицирует
ответ как блокировку, ничего не пишет в базу и откладывает задачу.

Больше запросов с этого IP не отправляли. Обходить защиту (стена логина,
капча, проверка на бота) по ТЗ нельзя.

Варианты (по спецификации):

1. **Платный провайдер данных Instagram** (ProviderSource) — основной источник
   или резерв. Те же IgProfile / IgMedia / IgMetrics, без блокировок на нашей стороне.
2. **Резидентные прокси** одного провайдера, ≤ 30 запросов в час на IP, sticky-сессия
   на задачу. Дешевле, но стена логина возможна и с ними — нужен PoC.

Списки заказчика загружены (10 брендов, 164 аккаунта в очереди на первый сбор):
сбор стартует, как только появится источник.
